# 智慧行動電源與 15 秒快充超時保護系統 (Smart Power Bank Controller)

## 1. 專案簡介
本專案為基於 NUCLEO-G474RE 開發板實作之「智慧行動電源管理系統」。系統模擬了現代快充行動電源的核心控制邏輯，具備即時電量監控、UART 遠端指令調節、軟體 PWM 亮度指示，以及關鍵的 15 秒硬體級過充保護機制，確保裝置在極端狀態下能自動進入安全降載模式。

## 2. 情境故事
隨著智慧型手機與穿戴裝置的快充需求日益增加，充電安全成為設計核心。許多老舊裝置或損壞的充電線可能導致「持續請求高功率」的錯誤狀態，進而引發電池過熱或膨脹。
為了解決此痛點，本專案設計了一套「15 秒快充超時保護」的防呆機制。當裝置啟動快充模式超過 15 秒仍未結束時，系統將強制介入，自動切斷高功率輸出（進入微光安全模式），直到使用者親自檢查裝置並按下實體按鈕重新授權，藉此最大化保護使用者的生命財產安全。

## 3. 硬體架構與腳位表
本專案硬體主要依賴 STM32 內部計時器與外部中斷，配置如下：

| 元件 / 功能 | 腳位 / 資源 | 設定細節與用途 |
| :--- | :--- | :--- |
| **狀態指示燈 (LED)** | `PA5` (GPIO_Output) | 透過軟體 PWM 控制亮度，100% 電量為最亮。進入保護模式時亮度降為 1%。 |
| **系統重置按鈕** | `PC13` (GPIO_EXTI) | 設為 Rising Edge 中斷，內建 150ms 軟體防彈跳。按下後電量恢復 100% 且解除保護。 |
| **通訊介面 (UART)** | `LPUART1` (`PA2`/`PA3`) | Baud Rate 115200，啟用全域中斷，配合 Ring Buffer 接收終端機操作指令。 |
| **系統主計時器** | `TIM2` (Timer) | 設定於 170MHz 產生 1ms 中斷，用於精準驅動 100Hz 軟體 PWM 與 15 秒超時運算。 |

## 4. 核心功能與系統邏輯
* **非阻塞式指令接收 (UART Ring Buffer)：** 採用環狀緩衝區架構處理 UART 接收中斷，避免主程式因等待通訊而卡死，確保系統即時反應電量增減指令。
* **精準軟體 PWM 控制：** 利用 TIM2 的 1ms 中斷作為基底，將 100ms 劃分為 100 個階層，動態映射電池電量至 PA5 的輸出 Duty Cycle。
* **15 秒安全降載保護：** 系統每過 1 秒 (1000ms) 會自動累加 `charge_seconds`，當計時達到 15 秒時，觸發 `Safe Mode`，強行將 PWM 輸出佔空比降至 1 (微光)，並停止電量消耗。
* **硬體中斷與防彈跳 (Debounce)：** PC13 按鍵觸發 EXTI 中斷，透過比對 `HAL_GetTick()` 實作 150ms 的防彈跳邏輯，過濾雜訊造成的重複觸發。

## 5. 程式目錄與結構
專案採用標準 STM32CubeIDE 結構，核心邏輯集中於以下路徑：
* `Core/Src/main.c`：主程式邏輯、UART 指令解析 (`while(1)`)。
* `Core/Src/stm32g4xx_it.c`：中斷服務常式 (ISR) 進入點。
* **中斷回呼函式 (Callbacks)：**
  * `HAL_UART_RxCpltCallback()`：處理字元接收並存入 Ring Buffer。
  * `HAL_TIM_PeriodElapsedCallback()`：處理 1ms 計時與軟體 PWM 狀態翻轉。
  * `HAL_GPIO_EXTI_Callback()`：處理按鈕防彈跳與系統狀態重置。

## 7. 安裝與編譯指南
1. 將本 GitHub Repository 複製 (Clone) 至本地端。
2. 啟動 STM32CubeIDE，選擇 `File` -> `Import` -> `Existing Projects into Workspace`。
3. 選擇本專案資料夾並點擊 Finish。
4. 點擊上方 `Project` -> `Build Project` 進行編譯 (確保 0 Errors)。
5. 將 NUCLEO-G474RE 透過 USB 連接至電腦，點擊 `Run` -> `Debug` 燒錄程式。

## 8. 操作說明與終端機指令
啟動專案後，請開啟 Tera Term，將序列埠 (Serial Port) 設定為開發板對應的 COM Port，Baud Rate 設為 **115200**。

**支援的鍵盤指令：**
* 輸入 `+`：模擬充電，電量增加 10% (最高 100%)。
* 輸入 `-`：模擬耗電，電量減少 10% (最低 0%)。

**硬體操作：**
* 按下開發板上的 **藍色 User Button (PC13)**：觸發系統重置，解除 15 秒保護模式。

## 9. 功能驗收標準
本專題須達成以下 4 項檢驗標準：
1. **即時狀態回報：** 終端機需精準「每秒」印出當前狀態 (如：`Timer: 1 / 15 s | Battery: 50%`)。
2. **電量動態回饋：** 輸入 `+` 或 `-` 時，綠色 LED (PA5) 亮度必須有肉眼可見的漸變。
3. **超時防呆機制：** 終端機計時達 15 秒時，需印出 `[WARN] 15s Timeout Reached! Safe Mode.`，且 LED 亮度強制降至極暗。
4. **按鍵硬體重置：** 在任何時刻 (包含保護模式下) 按下藍色按鈕，終端機需印出 `[INFO] System Reset!`，時間歸零且電量恢復 100%，並不得出現連點異常 (防彈跳成功)。

## 10. 常見問題與排除
* **Q: 終端機顯示亂碼？**
  * A: 請確認 Tera Term 的 Baud Rate 是否正確設定為 115200，且 Data 設為 8 bit, Parity 設為 none。
* **Q: 按下按鈕沒有反應？**
  * A: 請確認 PC13 腳位在 CubeMX 中是否正確設定為 GPIO_EXTI13，並在 NVIC 中啟用了對應的 EXTI Line 中斷。
* **Q: 輸入 + 或 - 無法控制電量？**
  * A: 請確認 LPUART1 的 Global Interrupt 已開啟，且在 `main.c` 進入 `while(1)` 前有呼叫一次 `HAL_UART_Receive_IT()` 啟動接收。
